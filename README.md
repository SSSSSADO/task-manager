# Task Manager

## Description

This project is a Django-based web application for task management.
It allows managing tasks & tags.

## Features

* Creating, removing, and updating Tags
* Creating, removing, and updating Tasks
* Adding tags to tasks

## Installation

```bash
git clone <your-repo-link>
cd your-project
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Run project

```bash
python manage.py migrate
python manage.py runserver
```
